- **Design System Ultra-Moderno:** Dark theme inspirado nas melhores interfaces do ecossistema de tecnologia (Vercel, Linear, Raycast), com glassmorphism, orbes de luz ambiente e microinterações fluidas.

  - **Physicos Jurerê:** Website institucional responsivo para estúdio de saúde e treino em Jurerê.
  - **Data Science & Algoritmos:** Coleção de notebooks Python para desafios matemáticos, cálculo de acurácia e consumo.
- **Stack Técnica Categorizada:** Front-end, Back-end & Dados, Cloud & DevOps, e Hardware & Eletrônica.
- **Trajetória Autêntica:** A história única de João Carlos Vieira unindo a formação de **Especialista em Eletrônica pela Força Aérea Brasileira (Aeronáutica - 1998)**, anos de experiência técnica em suporte/hardware, estudos em ADS na UNIVALI e sua sensibilidade criativa como **músico (saxofonista) e artista plástico**.

## 🚀 Como Executar Localmente

Como o projeto é construído em padrões web puros e modernos, basta abrir o arquivo `index.html` em qualquer navegador:

```bash
# Clone ou acesse a pasta do projeto:
cd "portfolio-joao-carlos-vieira"

# Opção 1: Abra diretamente com o navegador padrão no Windows
start index.html

# Opção 2: Ou execute com um servidor local rápido (Python ou npx serve):
python -m http.server 3000
# Acesse http://localhost:3000
```

## 🌐 Deploy Rápido na Vercel ou GitHub Pages

### Deploy na Vercel:
1. Instale o Vercel CLI (se ainda não tiver): `npm i -g vercel`
2. Na pasta do portfólio, execute: `vercel`
3. Siga as instruções no terminal para publicar instantaneamente.

### Deploy no GitHub Pages:
1. Crie um repositório no seu GitHub (`Deboshionkio/portfolio`).
2. Faça commit e push dos arquivos:
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio joao carlos vieira release v1.0"
   git branch -M main
   git remote add origin https://github.com/Deboshionkio/portfolio.git
   git push -u origin main
   ```
3. No GitHub, acesse **Settings > Pages** e selecione a branch `main` e pasta `/root`.
