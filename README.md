# Portfólio Profissional — João Carlos Vieira 🚀

Portfólio moderno, responsivo e de alta performance desenvolvido para apresentar a trajetória profissional, projetos em produção, competências técnicas e formação de **João Carlos Vieira** — Desenvolvedor Full Stack e Estudante de Análise e Desenvolvimento de Sistemas (ADS) na UNIVALI.

## 🌟 Destaques do Projeto

- **Design System Ultra-Moderno:** Dark theme inspirado nas melhores interfaces do ecossistema de tecnologia (Vercel, Linear, Raycast), com glassmorphism, orbes de luz ambiente e microinterações fluidas.
- **Spotlight Case Study:** Apresentação aprofundada da plataforma em produção da **Fabíola Góes Arquitetura & Habite-se**, destacando simulador de orçamento, slider interativo antes/depois, quiz de estilo e rastreamento analítico com Google Analytics 4 (GA4).
- **Projetos Selecionados com Filtro Interativo:**
  - **Smart_Tank:** Gestão de consumo veicular e abastecimentos em React 18, TypeScript, Tailwind CSS e Supabase.
  - **Endolipo 2.0:** Plataforma web estética de alta performance com TanStack Start, React 19, Tailwind v4 e Radix UI.
  - **Colinha Digital SC:** Web app mobile-first offline para eleitores salvarem candidatos no celular.
  - **Meu Filtro Apoiadores:** Manipulação dinâmica de imagens em Canvas HTML5 com zoom e moldura personalizada.
  - **QR Code Free:** Gerador e customizador instantâneo de QR Code vetorial.
  - **Inventário RPG:** Arquitetura de Orientação a Objetos em Java com coleções e padrões.
  - **Physicos Jurerê:** Website institucional responsivo para estúdio de saúde e treino em Jurerê.
  - **Data Science & Algoritmos:** Coleção de notebooks Python para desafios matemáticos, cálculo de acurácia e consumo.
- **Stack Técnica Categorizada:** Front-end, Back-end & Dados, Cloud & DevOps, e Hardware & Eletrônica.
- **Trajetória Autêntica:** A evolução profissional de João Carlos Vieira integrando sua formação em **Análise e Desenvolvimento de Sistemas (UNIVALI)**, constante capacitação em back-end e IA na **DIO**, mais de duas décadas de prática em computação e hardware (com qualificação pela **Study Data Florianópolis** desde 2003), valores de disciplina como militar da reserva (concursado federal - especialização BET em eletrônica básica) e sensibilidade criativa como **músico e artista plástico**.
- **Canais de Contato com 1 Clique:** Integração direta com WhatsApp, botão de cópia de e-mail com toast animado, LinkedIn, GitHub e relógio com horário local de Florianópolis (GMT-3) em tempo real.

Como o projeto é construído em padrões web puros e modernos, basta abrir o arquivo `index.html` em qualquer navegador:

start index.html
